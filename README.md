# 基于计算模型的中国人口预测

## 数值分析课程设计配套仓库

本仓库为南京农业大学《数值分析课程设计》课程论文配套项目，基于1949—2025年中国人口统计数据与第七次全国人口普查年龄结构数据，分别构建**线性增长模型、Logistic阻滞增长模型、Leslie年龄结构矩阵模型**，采用最小二乘法、非线性拟合与矩阵迭代等数值分析方法完成参数求解与精度对比，实现2031—2050年中国总人口的多情景预测。

---

## 📚 项目简介

人口预测是社会经济发展规划的核心基础数据支撑。本项目以中国人口发展历程为研究对象，从总量拟合与结构推演两个维度构建三类数学模型，通过训练集拟合、验证集精度对比筛选最优模型，并设置高、中、低三种生育率情景，对2031—2050年中国总人口规模、下降趋势与老龄化进程进行量化预测，同时分析人口变动的驱动因素并提出政策建议。

---

## 📐 核心模型与方法

### 1. 线性增长模型

假设人口随时间呈匀速线性变化，通过一元最小二乘法拟合历史人口趋势，形式为：

$$N(t)=a+bt$$

- **参数结果**：截距 $a=52110.4$，斜率 $b=1112.6$
- **精度表现**：训练集RMSE = 1197万人，验证集RMSE = 643万人
- **局限性**：无法刻画人口增长放缓与负增长转折，仅适用于短期高速增长阶段拟合

### 2. Logistic阻滞增长模型

引入环境容纳量 $K$ 描述资源约束下的S型增长规律，通过Levenberg-Marquardt非线性最小二乘算法求解参数：

$$N(t)=\frac{K}{1+\left(\frac{K}{N_0}-1\right) e^{-r(t-t_0)}}$$

- **参数结果**：环境容纳量 $K=146520$ 万人，内禀增长率 $r=0.0627$
- **精度表现**：训练集RMSE = 856万人，验证集RMSE = 468万人
- **局限性**：仅能刻画总量放缓趋势，无法预见人口负增长与年龄结构变化

### 3. Leslie年龄结构矩阵模型

按5岁间隔将人口划分为20个年龄组，构建包含生育率、存活率的人口转移矩阵，通过逐年迭代推演分年龄人口分布：

$$n(t+1)=L \cdot n(t)$$

- **参数基础**：以2020年七普分年龄人口为基期，结合年龄别死亡率、育龄妇女生育率构建矩阵
- **精度表现**：训练集RMSE = 402万人，验证集RMSE = 278万人，三类模型中拟合精度最优
- **情景设置**：
  - 低方案：总和生育率维持1.09并缓慢下降
  - 中方案：总和生育率逐步回升至1.4
  - 高方案：总和生育率逐步回升至1.7

## 🔬 主要研究结论

1. **人口已进入持续负增长阶段**：截至2025年末全国总人口约14.05亿，人口自然增长率降至-2.41‰，连续四年负增长；60岁及以上人口占比达22.86%，老龄化加速推进

2. **Leslie模型预测性能最优**：依托年龄结构信息，Leslie模型拟合误差显著低于线性与Logistic模型，是中长期人口预测的合适方法

3. **未来人口将持续加速下降**：中生育率情景下，2031年总人口约13.85亿，2040年降至13.36亿，2050年进一步降至12.63亿，20年间累计减少约1.7亿人；高情景下2050年约13.57亿，低情景下约12.10亿

4. **老龄化程度持续深化**：预计60岁及以上人口占比将在2035年前后突破30%，对社保、医疗与养老体系形成持续压力

5. **生育率下降驱动因素复合化**：生育约束已从政策限制转向经济成本、婚育观念等社会经济因素的综合作用，单一补贴政策扭转低生育率的效果有限

## 💻 计算复现说明

本项目全部数值计算基于R语言实现，核心依赖与步骤如下：

### 环境依赖
- R 4.0+
- 依赖包：`stats`（内置线性回归）、`minpack.lm`（非线性最小二乘拟合）

### 核心步骤
1. 导入1949—2013年人口数据作为训练集
2. 分别调用`lm()`与`nlsLM()`求解线性模型、Logistic模型参数
3. 基于七普年龄结构数据构建Leslie矩阵，编写迭代函数逐年计算人口分布
4. 代入验证集数据计算RMSE，对比三类模型精度
5. 设置三种生育率情景，输出2031—2050年预测结果
