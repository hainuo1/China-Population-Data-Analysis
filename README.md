# China Population Data Analysis & Forecasting
## Project Overview
This project uses R programming combined with Logistic model & Leslie matrix to fit official historical China population data, implement medium-long term population prediction, and propose reasonable population policy suggestions.

## Environment Requirement
- R ≥ 4.2.0
- Core dependency packages: tidyverse, ggplot2, forecast
